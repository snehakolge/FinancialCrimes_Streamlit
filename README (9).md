# 🏦 Real-Time Financial Crime Intelligence Platform

## 🔥 Overview
A multi-agent AI system for fraud detection, AML monitoring, and RBI compliance using LangGraph and real-time decision intelligence.

---

## 🧠 Architecture

Fraud Agent → AML Agent → RBI Agent → Fusion Risk Engine → Decision System

---

## ⚙️ Features

- Multi-agent fraud detection
- AML pattern detection
- RBI compliance rule engine
- Risk scoring engine
- Real-time SOC dashboard
- Synthetic transaction simulation

---

## 🚀 Tech Stack

- Python
- LangGraph
- Streamlit
- Pandas
- Plotly

---

pip install -r requirements.txt
